# SMM2 Pause Cutter

マリオメーカー2の録画からポーズ区間を検出し、確認・調整してMP4へ書き出すWindows用ツールです。
任天堂とは無関係の非公式ツールです。ゲーム映像・ロゴは配布物に含めません。

## ダウンロード

実行用ZIPは、このリポジトリの [Releases](https://github.com/ty79245243-ops/smm2-pause-cutter/releases) に掲載します。
2.6.1はコミュニティ共有用です。開発PCで起動・解析・書き出しを確認しています。別PCでの動作確認は未実施です。
実行用ZIPには必要な部品と対応ソースを同梱し、Pythonの導入や初回のダウンロードは不要です。
GitHubが自動生成する「Source code」はソース用で、実行用ZIPとは異なります。

## 使い方

1. 実行用ZIPをすべて展開して `SMM2PauseCutter.exe` を起動します。`_internal` も必要です。
2. 元動画を選択します。
3. 音声を選びます。初期設定は **消音** です。
4. 「ポーズを解析」を押します。
5. 検出件数・削除時間を確認します。区間一覧は初期状態で閉じています。必要なら「区間一覧を開く」で確認・調整します。
   表は「すべて／通常のみ／要確認のみ」に切り替えられます。チェックを外した区間は残します。
6. 左下の「MP4を書き出す」で別名保存します。元動画は変更しません。

白い数値欄で削除開始・終了を変更できます。Enterか入力欄の外をクリックすると確定、Escで取消です。
変更した行は青い「リセット」で解析直後に戻せます。フレーム番号は1始まり・両端を含みます。

## 対応条件

- Windows 10/11・64bit。実際の検証環境はWindows 11です。管理者権限は不要です。
- 画面全体が16:9のゲーム映像で、黒帯・配信枠・独自オーバーレイがない動画。
- MP4 / M4V / MOV / MKV / AVI のローカルファイル。
- 固定fps。30/60/120fpsと480p/720p/1080p/2160pで検証しました。可変fpsは拒否します。
- ポーズ画面の右上に、検証したものと同じ位置・形の✕ボタンがあること。
- 強い圧縮で✕が潰れている場合や、極端に短いポーズでは検出漏れがあり得ます。

ポーズ検出は1920×1080の `(1809,33)`〜`(1880,104)` を基準にした✕領域だけです。
座標は解像度に比例させ、必要な場合はその小領域だけ72×72に揃えます。
前後の一致判定は160×90の白黒画像を使います。メニューがない重複フレームは削除しません。
別画面へ移るやりなおし等は「カットしない」で表示し、長い自然な静止時間は保守的に残します。

「要確認」は復帰画面が一致しない・境界不明・区間の重なり等の判定です。アプリの処理エラーとは区別します。
通常の区間を手動でカットしない設定にしても要確認へ分類しません。要確認の区間を手動でカット予定にしても分類は維持します。
表示フィルターは確認のためのものです。非表示の区間もチェック状態に従って書き出します。

## 音声・画質・保存

カットの継ぎ目で音が途切れるため、消音が初期設定です。音声を残す設定も選べます。
映像はH.264/CRF 18、元の解像度・fpsで再エンコードします。完全な無劣化編集ではありません。
元動画の上書きはしません。MP4と同じ場所へ `.cuts.json` を保存します。
カット記録に保存するパスはファイル名のみです。動画・ログ・記録の外部送信機能はありません。
一時キャッシュは60fpsで約52MB/分を使います。解析・書き出しには空きディスク容量が必要です。

## 不具合とセキュリティ

操作上の問題は [Issues](https://github.com/ty79245243-ops/smm2-pause-cutter/issues) へ報告してください。
バージョン・OS・解像度・fps・再現手順を添えてください。個人情報入りの動画やログをそのまま公開しないでください。
ログは `%LOCALAPPDATA%\SMM2PauseCutter\logs\app.log` に保存し、最大約3MBで循環します。
ホームディレクトリ文字列は置き換えますが、ファイル名等が残る可能性はあります。
脆弱性報告と確認範囲は [SECURITY.md](SECURITY.md)、更新履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。
